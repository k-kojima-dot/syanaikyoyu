- `index.html` … 本体。**外部依存なし**（Tailwind／Font Awesome／フォントを全て内蔵）。ブラウザで開くだけで動きます。
- 当日施工の可否を現場条件から判定するインタラクティブなシミュレータ入り。

## 公開方法（GitHub Pages）

1. GitHub で新しいリポジトリを作成
2. このフォルダを push（下記コマンド）
3. リポジトリの **Settings → Pages** を開く
4. **Build and deployment → Source: Deploy from a branch**、**Branch: `main` / `root`** を選択して保存
5. 数分後に発行される `https://<ユーザー名>.github.io/<リポジトリ名>/` を社内へ共有

### push コマンド例

```bash
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```
