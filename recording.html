はじめる前に

2つだけ確認する

  1. サインインしているアカウントを確かめる

    emmet.uketsuke@gmail.com（内線806）が対象です。+1 / +2 / +3 の付いたアカウントには録音の閲覧権限がありません。

    内線番号は「電話 → 設定」で確認できます。821 と表示されていたら +3 のアカウントです。

  2. 「Try new experience」をオフにする
    Try new experience← この状態に

    画面右上のトグルです。オンだと新しい「管理センター」に切り替わり、左メニューが アカウント / 製品設定 / コンテンツ管理 の3つだけになります。

    この手順書はオフの画面が前提です。見覚えのない画面が出たら、まずここを疑ってください。

ルート A

自分の通話を聞き直す

日常的にはこちらだけで足ります。「さっきの電話をもう一度聞きたい」はすべてここです。

A

電話 → レコーディング

自分がかけた・受けた電話
  1. 左メニューの「電話」を開く
    ウェビナー Events 電話 個人連絡先 個人用デバイス

    「ウェビナー」「Events」のすぐ下にあります。

  2. 上部タブを「レコーディング」に切り替える
    履歴ボイスメールレコーディング設定
  3. 日付の範囲を広げる
    2026/08/15 2026/08/21

    初期表示は直近7日間だけです。それより前の通話を探すときは、開始日を書き換えます。

    「録音が無い」と感じたときの原因は、ほとんどがこれです。

  4. 再生する・保存する
    発信元レコーディング
    まちの金庫救急隊 内線815▶ 0:08:57ダウンロード
    まちの金庫屋さん 内線808▶ 0:02:15ダウンロード

    再生時間をクリックするとその場で再生されます。行の右端の … からは文字起こしも開けます。

ルート B

キューにかかってきた電話を探す

「誰が取ったか分からないが、この番号への電話を聞きたい」ときだけ使います。

B

電話システム管理 → ログ → レコーディング

対象6キューの着信すべて
  1. 左メニューを下までスクロールし、「電話システム管理」を開く
    管理者 ユーザー管理 電話システム管理 └ ログ

    「管理者」のグループが見当たらないときは、一度サインアウトして入り直します。

  2. 上部タブを「レコーディング」に切り替える
    通話SMSレコーディングボイスメール

    直接開くならこちら。

    us06web.zoom.us/pbx/page/telephone/callLog#/recording-list
  3. 日付を広げてから絞り込む

    ここでも初期値は直近7日間です。範囲を広げたうえで、「名前、内線、または番号で検索」に相手の電話番号を入れるのがいちばん速い探し方です。

    キュー単位で見たいときは「オーナータイプ」をコールキューに絞ります。

  4. 再生する・保存する

    操作はルートAと同じです。削除ボタンは表示されません（誤削除を防ぐため、権限から外してあります）。

困ったとき

症状から原因を引く

一覧が空っぽで、1件も出てこない 日付の範囲が狭すぎます。どちらの画面も初期値は直近7日間です。開始日を先に広げてください。
電話の録音がどこにも見当たらない 「レコーディングと文字起こし」を開いていませんか。そこは会議の録画置き場です。「電話」から入り直してください。
見覚えのない画面になった 右上の Try new experience がオンです。オフに戻すと、この手順書どおりの画面に戻ります。
「このページにアクセスする権限がありません」 開くページが違います。「電話ユーザー」「ユーザーとルーム」など電話の管理設定ページには権限がありません。開けるのはレコーディングのページだけです。
「電話」を開いたら初期設定の画面が出た 別のアカウントにサインインしています。内線番号を確認してください。806 以外なら +1 / +2 / +3 のアカウントです。
左メニューに「管理者」が出ない 一度サインアウトして入り直してください。権限の反映に数分かかることがあります。
特定のキューだけ録音が無い そのキューの自動通話録音がオフの可能性があります。管理者に確認してください。
取り扱い

2つの約束

録音は削除できません。誤って消してしまうことを防ぐため、権限から外してあります。削除が必要なときは管理者に依頼してください。 録音はお客様の個人情報です。ダウンロードしたファイルの保存先・共有先には十分ご注意ください。社外への持ち出しは行わないでください。
ロール「受付_録音閲覧」／権限：レコーディングの表示・再生・ダウンロード（削除は不可） 設定の変更が必要なときは管理者（sales@emmet-grp.com）まで。
